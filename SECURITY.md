# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.5.x   | :white_check_mark: |
| < 2.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within **YT Archiver Studio**, please do **not** open a public issue. Instead, report it responsibly:

1. **Email or Private Advisory**: Open a Private Security Advisory on GitHub or email the maintainers directly.
2. Please include:
   - A clear description of the vulnerability and potential impact.
   - Step-by-step reproduction steps or proof-of-concept.
   - Affected platform / OS details.

We will review and acknowledge your report within 48 hours and work on a fix in a private release branch before publishing an update.
